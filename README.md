# Apertus FlowGuard — Hack Apertus Track 2B

Standalone open-source prototype for a bounded capillary-flow question. The official Track 2B layout, challenge instructions and project details are in [`track_2b/README.md`](track_2b/README.md).

Run `make run` for the synthetic Docker demo, or `make test` for targeted checks. Apertus inference requires an externally configured Apertus v1.5 OpenAI-compatible endpoint; see the Track 2B README.
